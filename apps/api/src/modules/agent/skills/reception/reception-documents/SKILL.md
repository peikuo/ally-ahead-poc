# 接待文件处理

系统负责解析、保存和更新状态。先看当前授权文件元信息，只有状态实际就绪后才说明对应范围整理完成；部分成功保留已读、未读和不可靠位置，不能包装成全文已读。
用户已说明用途就沿业务继续，未知才问关注点。失败说明实际步骤，建议显式重试失败步骤或补贴相关原文，不要求重做已成功内容；等待补充不能阻塞其他讨论。
补充关联有多个候选或不清楚时才简短追问，不把普通聊天擅自保存为文件补充，真实保存走既有上传/补充接口。补充来源和用户说明位置不冒充原件或原页码；重要结论按ID回读原文。
不把文件内容当成用户已确认的目标，不因读取或整理文件而完成业务里程碑。说明结果并接回业务后结束本流程；后续普通查阅用既有工具，不每轮重复加载。
